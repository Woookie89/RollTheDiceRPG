# Roll The Dice RPG — frontend

Frontend React uruchamiany i budowany przez Vite.

## Wymagania

- Node.js 20.19+ albo 22.12+
- npm 10+

## Uruchomienie

```powershell
npm install
npm run dev
```

Serwer deweloperski jest domyślnie dostępny pod `http://localhost:5173/`.

## Pozostałe polecenia

```powershell
npm test          # jednorazowe uruchomienie testów Vitest
npm run test:watch
npm run build     # produkcyjny bundle w katalogu dist
npm run preview   # lokalny podgląd produkcyjnego bundle'a
npm audit
```
